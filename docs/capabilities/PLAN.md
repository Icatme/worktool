# 独立能力协议与 Go SDK

基线：`a614299530d61adf4edb6345b10c5252aca19157`。定位为内部 Android APK；本轮不发布 APK、不合并 PR、不接入真实账号。

## 本轮交付

| 批次 | 改动 | 本地验收 |
| --- | --- | --- |
| 1 | v1 语义、JSON Schema、共享样例 | JSON 可解析；字段、状态、错误和能力声明一致 |
| 2 | 无 Android 依赖的 Kotlin 核心、独立 Go module、可注入通道 | Go test/race/vet；Kotlin 单测；双方实际编码的 JSON 由另一方解码 |
| 3 | APK 本地策略、默认离线、受限文本执行与消息观察 | 单测、Debug/Release 构建、lint、独立代码审核；远端草稿 PR head 核对 |

后续批次依赖前一批，分别建立草稿 PR。提交带 `[skip ci]`，不添加或触发 GitHub Actions。

## 边界

APK 是执行端：接收命令、发出执行结果、发出观察事件。Go SDK 负责类型、关联、等待、订阅和错误；调用方负责显式提供通道。通道必须先认证远端，再把受信身份及授权范围交给 APK，不能相信 JSON 自报身份。SDK 不内置地址、机器人号、共享密钥、WebSocket 自动连接或重连。测试身份仅用于假通道，不构成生产认证。

第一批能力为 `state.get`、`capabilities.get`、`text.send` 和 `message.observed`。不把历史源码中的所有数字命令声明为已支持。文件上传、群管理、联系人增删、群发、截图传输、AI 对话、知识库、网关、隧道、服务端和 JZ/OCAI 集成都不在本轮。

文本发送只针对**本机用户选定的当前会话**。目标使用短期不透明句柄；显示名称仅为 UI 信息，不能作唯一键，不搜索首个同名联系人。绑定失效、节点不唯一、界面变化、暂停、权限不足或本地未允许时拒绝。发送不自动重试；点击发送不等于服务端送达。发生了可能执行的动作但不能证明最终状态时返回 `unknown`，不得伪报成功。

消息观察只读取本地选定会话中能看见的纯文本。初次快照作为基线，不上传历史；不点击、翻页、入群或自动遍历会话。这是尽力观察事件，不是企业微信服务端完整消息流，不承诺无遗漏。必须显式本地开启，默认关闭。

旧平台配置/数字协议保留为显式兼容模式；默认不启用。旧模式和新能力互斥，防止两个执行器同时操作 UI。已有默认商业地址不能让新模式隐式连接。开启旧模式属于用户自己的显式配置操作；本次开发不连接该服务。

## 设计取舍

- 命令有独立 ID；批次不共享去重身份。接收、开始执行、执行终态是不同事实。
- 执行会话 ID 每次执行端实例重建更换。去重账本只在该会话内有效，达到上限后拒绝新命令，不驱逐旧记录后悄悄重做。进程重启后旧会话命令被拒绝。
- 相同 ID/相同语义重投只回最近结果；相同 ID/不同语义报冲突，原命令继续保持原状态。
- 超时、断线、取消等待不代表未执行，SDK 不自动重发。远程撤销动作不是 v1 能力。
- 结果与事件独立；事件不能结束命令等待。终态和序号检查防止乱序回执倒退。
- 长期认证、设备注册/密钥轮换、持久结果查询、稳定会话身份和可靠消息源仍需后续设计，不用假接口声称完成。

## 尚需设备验收

只在用户另外批准的测试设备/测试账号上进行：

1. Android 14/15/16（及 minSdk 24 代表机）安装、授权、暂停/恢复、锁屏/切换应用后确认不会误发。
2. 本地绑定当前聊天后发送一条测试文本；确认重名、切换聊天、旧句柄、重复命令都不会投错目标或重发。
3. 验证企微版本对应的输入框、发送按钮和消息列表结构；不匹配必须拒绝。记录实际版本，不能据构建通过宣称全兼容。
4. 观察事件开启前/关闭后无输出，初次绑定不发历史；新消息、同文多条、列表重排/滚动正确处理或明确丢弃。
5. 假通道断线/重接、进程重启、用户暂停与命令并发，检查结果的不确定性和去重范围。
6. 单独验证旧模式显式启用/关闭，默认启动没有商业网络流量。不得借此次开发连接真实服务器验证。
