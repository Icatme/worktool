# 本轮实施范围

本分支是待验收的内部应用迁移，不是发布版本。应用版本号仍为 2.8.1 / 28011；
主源码基线为 2023 年历史代码，不能把上游 README 的商业版兼容声明用于此构建。

## 工具链和依赖

采用方案中的 JDK 17 / AGP 8.13.2 / Gradle 8.13 / Kotlin 2.3.10 / API 36，
保留 minSdk 24 和应用字节码 Java 8。三个 Android 模块加入 namespace、
ViewBinding、显式 BuildConfig；移除 Kotlin synthetic。Gradle wrapper 固定 SHA-256，
关闭 SDK/JDK 自动下载，不自动安装组件或接受许可。

依赖只经 Google Maven / Maven Central 解析；插件使用官方 Gradle Plugin Portal。
无法在这些仓库取得的 OkGo 被应用自己的薄 HTTP 层替换，底层为 OkHttp 4.12。
HTTP 响应最大 1 MiB，下载最大 25 MiB，保留平台 TLS 证书校验，禁用连接失败自动重试。
ZXing core 替代旧二维码封装；删除未使用的旧 UI 依赖、统计初始化与自动商业版更新。
完整依赖哈希和许可审查边界见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 平台行为

- launcher 显式 exported，内部入口关闭；自定义广播仅本应用收发并随生命周期注销。
- 录屏由用户在前台点击入口、阅读说明、完成系统授权后启动 mediaProjection FGS。
  每次授权只创建一次 VirtualDisplay，多帧读取共用同一会话；尺寸变化更新该会话。
  系统停止、通知停止、服务销毁后释放资源；进程重启不复用授权。静止画面保留最近一帧；
  API 24–33 屏幕配置变化时结束会话并提示重新授权，避免尺寸错位。
- 不再监听企微私有 imagecache；`pushImage` 默认关闭，并要求有效录屏会话。
  Android 14+ 自带锁屏/系统停止行为仍需设备验证。
- 只声明需要的包查询；不再请求 QUERY_ALL_PACKAGES。FileProvider 仅共享子目录，
  每次分享生成有大小上限的私有快照，URI 只有临时读取权限，并保留请求文件显示名称。
  文件分享失败停止后续选择收件人的步骤。
- 悬浮控制使用声明了理由的 specialUse FGS；禁止后台启动时提示回到应用。
  无障碍服务没有被改成 dataSync FGS，不适用该类型的六小时限制。
- 页面根视图处理系统栏/cutout inset；具体屏幕、旋转与键盘布局还未通过设备检查。

## 明确暂不支持的能力

随仓库附带的 WWAPI 2.0.12.11 使用旧式动态广播注册，不能在 target 36 下直接初始化。
本轮将该 SDK 初始化和分享开关固定关闭；链接/小程序 SDK 分享返回明确错误，不执行
下载或发送。源码和原有 AAR 保留供后续核验；恢复功能必须先核实官方 SDK 来源、许可、
动态广播身份验证、PendingIntent、目标包可见性并补设备测试，不能只翻转开关。

群二维码原实现自动保存并遍历 `/DCIM/WeixinWork`，缺少用户授予的图片 URI。
本轮删除这条读相册路径并禁用设置项，不恢复历史存储的开关值。以后使用用户选择
图片/授权截图后再解码。基础文本路径不依赖这两个功能。

旧连接重试、名称选人和其他企微 UI 自动化保留为历史行为，尚未验证新企微版本。
不能把此迁移理解为全部命令已兼容；其验收顺序仍是只读页面、唯一测试联系人、
单条文本发送与接收、明确结果，再逐项扩大能力。
